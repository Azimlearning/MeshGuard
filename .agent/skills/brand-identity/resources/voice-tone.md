# Copywriting: Voice & Tone Guidelines

When generating text for the Resilience Radar dashboard or reports, adhere to this persona.

## Brand Personality Keywords
* **Professional:** Authoritative and data-driven.
* **Empathetic:** Aware of the sensitivity of mental health topics (SDG 3).
* **Direct:** Efficient information delivery.
* **Malaysian Context:** Use appropriate local terminology (e.g., District/Daerah, State/Negeri).

## Grammar & Mechanics Rules
* **Language:** English (Required per competition rules).
* **Headings:** Use Title Case for main headings (H1, H2).
* **Tone:** Objective when discussing data, supportive when discussing interventions.
* **Clarity:** Prefer active voice.

## Terminology Guide

| Context | Recommended Term |
| :--- | :--- |
| Suicide Prevention | Mental Health Resilience |
| Intervention | Actionable Strategy |
| Hotspot | High-priority Region |
| Data Source | Official Statistic (e.g., OpenDOSM) |
